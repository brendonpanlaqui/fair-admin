**Fair** is a dual-system platform designed to combat  overcharging in Angeles City. It consists of a React Native mobile application for commuters, and this is the Django-powered LGU administrative dashboard for the Public Transport Regulatory Office (PTRO).

---

## 🛠️ Prerequisites

Before you begin, ensure you have the following installed on your machine:
* [Node.js](https://nodejs.org/) (v18+ recommended)
* [Python](https://www.python.org/downloads/) (v3.10+ recommended)
* [PostgreSQL](https://www.postgresql.org/) (Running locally on port 5432)
* [Expo Go](https://expo.dev/client) (Installed on your physical mobile device)
